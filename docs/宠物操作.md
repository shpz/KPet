# 宠物操作

## 会话面板

点击关卡上的 Pawn 弹出来一个会话面板，

会话面板显示 Kimi Code CLI 的会话列表，

每个会话显示一行，

有 Agent 新回复的会话在行尾加消息气泡动画。

有 Agent 正在工作的会话要加上三个点动画。

会话激活要跟没激活的会话要有明显区别，比如高亮或者颜色区别。

点会话要跳转到对应的会话。

会话面板弹出和关闭都要有动画。

## 摄像机调整

对着 Pawn 按住 R 键和鼠标左键要能转动摄像机，

转动范围不要太大，你取一个合理的默认值，在 Pawn 上增加一个属性方便我后续调整。

对着 Pawn 按住 R 键和鼠标滚轮滚动要能控制摄像机靠近和远离 Pawn。

进行摄像机调整的时候，鼠标变成摄像机样子。
